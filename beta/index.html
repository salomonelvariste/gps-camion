Mon GPS Camion

GPS gratuit pour camion + trailer
Pour commencer (une seule fois) :
1. Créez une clé gratuite sur account.heigit.org (ligne « Basic Key », bouton bleu à deux carrés pour copier).
2. Collez-la dans ☰ Menu › Réglages.
3. Mettez les mesures de votre camion dans ☰ Menu › Camion.
Important : cette application aide à choisir une route, mais les cartes peuvent contenir des erreurs ou des manques (ponts bas, limites de poids, limites de vitesse, radars). Regardez toujours les panneaux. Ne touchez pas le téléphone en roulant : préparez la route avant de partir.
